Settings

Everything here stays in this browser. SlopMachine has no account, no server and no analytics.

Sites

SlopMachine reads only the box you are typing in, and only on sites you turn on. Chrome asks you to confirm each one.

Other sites Experimental

Works with plain text boxes on most sites. If a site's editor won't take an edit safely, you get Copy instead of Apply. Use *.example.com to cover a domain and all its subdomains.

    Rules

    Each rule is a style note, not a verdict. Turn off the ones that don't fit how you write.

    Rewrite engine

    Checking always happens on this device. A rewrite only runs when you press Rewrite, and only through the engine you pick here.

    Engine

    Ollama blocks browser extensions by default. Start it with OLLAMA_ORIGINS=chrome-extension://. In LM Studio, turn on CORS in the server settings.

    Provider
    Keep the key

    Your data

    Drafts are never stored. These controls cover settings and keys.

    Export settings

    Sites, rules and engine choice as a JSON file. Never includes drafts or keys.

    Import settings

    Replaces your current settings with a file you exported.

    Forget this session

    Clears the session-only key and anything held until Chrome closes.

    Delete everything

    Removes all settings, saved keys and site access.
